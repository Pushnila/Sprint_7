# Sprint 7 — API-тестирование сервиса «Яндекс Самокат»

Проект содержит API-автотесты учебного сервиса «Яндекс Самокат».

## Проверенные сценарии

### Создание курьера

- успешное создание курьера;
- создание двух одинаковых курьеров;
- создание курьера без обязательных полей;
- проверка кода и тела ответа.

### Авторизация курьера

- успешная авторизация;
- авторизация с пустым обязательным полем;
- авторизация с неверным логином или паролем;
- авторизация несуществующего курьера;
- проверка наличия `id` в успешном ответе.

### Создание заказа

Проверяется создание заказа:

- с цветом `BLACK`;
- с цветом `GREY`;
- с двумя цветами;
- без указания цвета.

Успешный ответ проверяется на наличие номера заказа `track`.

### Получение списка заказов

Проверяется, что успешный ответ содержит список в поле `orders`.

## Структура проекта

- `tests/` — API-тесты;
- `conftest.py` — фикстуры и очистка тестовых данных;
- `data.py` — тестовые данные;
- `helpers.py` — генерация уникальных данных;
- `urls.py` — адреса API;
- `allure_results/` — результаты запуска для Allure;
- `pytest.ini` — настройки Pytest;
- `requirements.txt` — зависимости проекта.

## Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

## Запуск тестов

```bash
python -m pytest -v
```

## Создание результатов Allure

```bash
python -m pytest --alluredir=allure_results --clean-alluredir
```

## Просмотр отчёта Allure

```bash
allure serve allure_results
```
